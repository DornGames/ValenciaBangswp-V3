| 代码 | 名称 | 功能 |
| :--- | :--- | :--- |

| **d.** | 动词 | 表示动作、行为、状态。 |
| **s.** | 形容词 | 修饰名词，表示性质或状态。 |

## 第三部分：构词法与词缀系统（核心细节）

### 3.1 名词（m.）相关的词尾变化

| 功能 | 词缀 | 条件/规则 | 示例 |
| :--- | :--- | :--- | :--- |
| **复数** | `-s` | 仅用于可数名词，统一加在词尾。 | `tab`（书）→ `tabs`（书们） |
| **序数词** | `-v` | 加在数词词尾。 | `va`（一）→ `vav`（第一） |
| **名词化（动→名）** | `-iac` / `-iad` / `-iat` | 加在动词词干后，表抽象概念或结果。 | `haor`（想）→ `haoriat`（理想） |
| **名词化（动→名）** | `-iêr` / `-inh` | 加在动词词干后，表人或具体物。 | `mart`（饮食）→ `martiêr`（饮食活动） |
| **所属关系（of）** | `bich`（介动词） | 置于所有者与所属物之间。 | `司机 bich 出租车`（这辆车的司机） |

### 3.2 动词（d.）相关的词尾与形态变化

#### A. 动词化（名→动）
| 词缀 | 条件/规则 | 示例 |
| :--- | :--- | :--- |
| `-iêt` / `-hiêt` | 加在名词词干后。 | `slaip`（课）→ `slaiphiêt`（授课） |
| `-od` | 加在名词/形容词词干后。 | `lonp`（面积）→ `lonpod`（面积为） |

#### B. 主时态词尾（谓语动词限定式）
*注：加在整个谓语动词（含派生词缀）的最末尾。*

| 时态 | 词尾（辅音结尾） | 词尾（元音结尾） | 示例（`rerr` 吃） |
| :--- | :--- | :--- | :--- |
| **现在时** | `-if` | `-kif` | `rerrif`（正在吃，注意不是一般现在时，一般现在时正常叙述来说可以不加-if） |
| **过去时** | `-ah` | `-pah` | `rrerrah`（吃了） |
| **将来时** | `-it` | `-xit` | `rrerrit`（将吃） |

#### C. 分词形态（用于从句或副时态）
*注：形态与主时态词尾相同，但功能上可作为非谓语动词。*

| 分词名称 | 词尾（辅） | 词尾（元） | 示例 |
| :--- | :--- | :--- | :--- |
| 过去分词 | `-ah` | `-pah` | `rrerrah`（已吃的） |
| 现在分词 | `-if` | `-kif` | `rerrif`（正在吃的） |
| 将来分词 | `-it` | `-xit` | `rrerrit`（将吃的） |
| 被动分词 | `-op` | `-sop` | `rerrop`（被吃的） |

#### D. 语态分词（词头前缀）

| 名称 | 词头（辅音开头） | 词头（元音开头） | 功能 | 示例 |
| :--- | :--- | :--- | :--- | :--- |
| **使动分词** | `ki-` | `kih-` | 使...做某事 / 祈使句 | `ki-rerr`（使吃 / 吃！） |
| **意动分词** | `sle-` | `sleh-` | 觉得要... / 认为...是 | `sle-rerr`（觉得要吃） |
| **为动分词** | `plw-` | `plwh-` | 为...而做 | `plw-rerr`（为...而吃） |

### 3.3 形容词（s.）与副词（f.）的派生词缀

| 目标词性 | 词缀 | 来源 | 示例 |
| :--- | :--- | :--- | :--- |
| **形容词（s.）** | `-fak` | 名词/动词/代词 + fak | `mad`（我）→ `madfak`（我的）<br>`dorn`（湩国）→ `dornfak`（湩国的） |
| **副词（修饰动词）** | `-fakesht` | 形容词 + fakesht | `piw`（快）→ `piwfakesht`（快速地） |
| **副词（修饰句子）** | `-fakext` | 形容词 + fakext | `limilfak`（里程碑式的）→ `limilfakfakext`（里程碑式地） |
| **副词（修饰形容词）** | `-fakezt` | 形容词 + fakezt | `dæmit`（极度）→ `dæmitfakezt`（极度地） |
| **副词（修饰副词）** | `-fakest` | 形容词 + fakest | `dæmit`（极度）→ `dæmitfakest`（非常地） |

### 3.4 比较级与最高级（前置副词）

| 等级 | 副词 | 用法 |
| :--- | :--- | :--- |
| **比较级（更多）** | `nesh` | 置于形容词/副词前。例：`nesh fwash`（更高） |
| **比较级（更少）** | `zind` | 置于形容词/副词前。例：`zind fwash`（更低） |
| **同级比较（一样）** | `loht` | 置于形容词/副词前。例：`loht fwash`（一样高） |
| **最高级（最多）** | `neshn` | 置于形容词/副词前。例：`neshn fwash`（最高） |
| **最高级（最少）** | `zindn` | 置于形容词/副词前。例：`zindn fwash`（最低） |

## 第四部分：句法规则（SVO 详细语序）

### 4.1 基础语序（时间 > 地点 > 主语 > 谓语 > 宾语）
- **绝对规则**：若句子包含时间和地点状语，必须放在句首，且**时间先于地点**。
- **示例**：`昨天 房子后方 我 吃了 饭。`

### 4.2 介动词（ud.）句型
- **结构**：`主语 + 介动词 + 地点/对象`
- **关键**：**无需系动词（am/is/are）**，介动词直接充当谓语。
- **示例**：`我 ich'hanthên 房子。`（我在房子后方。）

### 4.3 形容词的位置与否定
| 位置 | 语义 | 示例 |
| :--- | :--- | :--- |
| **形容词 + 名词** | **肯定**（...的） | `bejan kehiad`（红色的楼房） |
| **名词 + 形容词** | **否定**（不...的） | `kehiad bejan`（楼房不红） |

### 4.4 副词的位置与否定（四态严格区分）

| 修饰对象 | 词尾 | 肯定位置 | 否定结构 |
| :--- | :--- | :--- | :--- |
| **动词** | `-fakesht` | **动词之前**。例：`piwfakesht cwpod`（快走） | **动词之后**。例：`cwpod piwfakesht`（走得不快） |
| **整个句子** | `-fakext` | 句首/句末（加逗号）或动词前。 | `sht + 副词`，仅限句首或句末。 |
| **形容词** | `-fakezt` | **形容词之前**。 | **形容词之后**（表“不...地”）。 |
| **另一副词** | `-fakest` | **被修饰副词之前**。 | `sht + 修饰副词 + 被修饰副词`。 |

### 4.5 连词“和”的列举规则
- **必须逐项列举**：不能像中文或英文那样省略中间的“和”。
- **示例**：`va hr læ hr hi`（一、二和三；字面：一和二和三）。

### 4.6 所有格（属格）的两种表达

| 结构 | 语义 | 示例 |
| :--- | :--- | :--- |
| **所有者 bich 所属物** | 纯粹所属关系（of，物理隶属）。 | `司机 bich 出租车`（这辆出租车的司机） |
| **所有者-fak 所属物** | 形容词性所有格（性质/身份）。 | `出租车 fak 司机`（出租车司机这个职业） |

### 4.7 被动语态
- **结构**：`受事 aizêr 施事 动词(过去被动分词 -op)`
- **示例**：`苹果 aizêr 我 rerrop.`（苹果被我吃了。）

### 4.8 祈使句（命令式）
- **肯定命令**：直接用**使动分词（ki-/kih-）+ 动词原形**。
  - `Kirerr!`（吃！）
- **进行命令**：`Kirerrif!`（使...现在吃，强调“一直吃”）。
- **否定命令**：`sht`（不）或 `daajd`（禁止） + 动词原形。`daajd` 语气更强。
  - `Daajd rerr!`（严禁吃！）

### 4.9 复合时态（副时态与二级时态）

**副时态（背景时态）**：
- **结构**：`smah + [时态词尾] + [已变分词的谓语动词]`
- 示例（背景过去，主句现在）：`Mad smahah rerrif ...`（我昨天说我今天吃...）

**二级时态（嵌套背景）**：
- 在 `smah` 的词尾**先加二级副时态词尾，再加二级主时态词尾**（从内到外叠加）。
- 示例：`smahahif`（表示背景为过去，且该背景动作正在进行）。

### 4.10 疑问句与否定句
- **疑问助词**：`wna`（置于句首或动词前，变陈述为疑问）。
- **特殊疑问词**：`tah`（什么）、`wni`（谁）、`gwna`（哪个）、`wno`（何时）、`wadheo`（为何）。
- **一般否定**：`sht` 置于被否定成分之前（除形容词/副词的特殊否定语序外）。
